#+TITLE: Build Simplification
#+STARTUP: overview

* Vision

Make ~swift build~ the primary tool for everything that doesn't need an
~.app~ bundle, and reduce ~xcodebuild~ / ~project.pbxproj~ to the bare
minimum required to ship a signed, sandboxed AppKit application. Every
piece of code should live in an SPM package or be generated by a script
from a flat manifest — no Xcode-UI-only state.

Done so far: ~91 extension dylibs collapsed into a single SPM static
library (~Packages/HSExtensions~); LuaSkin moved to SPM; per-extension
Xcode targets removed (96 → 4); pbxproj cut ~73%.

* Next Steps (build simplification)

** NEXT Drive "Copy Extension Lua Files" from a manifest
   ~project.pbxproj~ still hard-codes ~500 ~.lua~ references — every
   new extension means editing the pbxproj. Generate that build phase
   (or replace it with a Run Script phase) from a flat list, the same
   way ~Packages/HSExtensions/extensions.list~ drives the C glue.
   Goal: adding an extension touches only ~extensions/~ and one
   manifest file.

** NEXT Drop ~-undefined dynamic_lookup~ from ~Project-Base.xcconfig~
   The flag predates static linking and now hides real link errors
   (we already fixed three latent duplicate-symbol bugs it was
   masking). Remove it and resolve whatever surfaces.

** NEXT Move the ~hs~ CLI to ~swift build~
   The ~hs~ command-line tool is a small ObjC binary with no AppKit /
   XIB / entitlements story. It is the lowest-hanging target to lift
   out of Xcode into a plain SPM executable product. The main app's
   build phase would just copy the already-built binary in.

** TODO Shrink the Xcode-only surface
   What still legitimately needs Xcode: ~Info.plist~, entitlements,
   ~.xib~ files, the asset catalog, code signing, app-bundle layout.
   Everything else should be SPM or generated. Audit ~Hammerspoon/~
   for sources that could move into an SPM target consumed by the app
   shell.

** TODO Consolidate ~Build Configs/*.xcconfig~
   Six xcconfig files with overlapping layering. Once the items above
   land, fold them into the minimum set that distinguishes
   Debug/Release/Profile/Test.
