* Dependency Graph

Star topology. LuaSkin is the core, extensions are leaves, the app is the aggregator.

#+begin_example
┌─────────────────────────────────────────────────┐
│               Hammerspoon.app                   │
│                                                 │
│  Entry: MJAppDelegate.m → NSApplicationMain()   │
│  Embeds: LuaSkin.framework, hs CLI              │
└──────┬──────────────┬──────────────┬────────────┘
       │              │              │
       ▼              ▼              ▼
  ┌─────────┐  ┌────────────┐  ┌──────────────┐
  │ hs CLI  │  │ 92 extension│  │ SPM Packages │
  │ (tool)  │  │   dylibs   │  └──────────────┘
  └─────────┘  └──────┬─────┘
                      │
                      ▼
              ┌──────────────┐
              │   LuaSkin    │
              │ (framework)  │
              │ ObjC ↔ Lua   │
              └──────┬───────┘
                     │
                     ▼
              ┌──────────────┐
              │  Lua 5.4.7   │
              │ (static lib) │
              └──────────────┘
#+end_example

- Every extension dylib links ~LuaSkin.framework~. No extension depends on another.
- The Hammerspoon app target depends on all 92 dylibs + the ~hs~ CLI tool.
- LuaSkin statically links the Lua 5.4.7 interpreter.

* Standalone Tools

** Doc Generator (~scripts/docs/~)
Swift package producing ~BuildDocs~ CLI. Depends on ~swift-argument-parser~.
Used by ~just docs~ and ~just docs-lint~. Builds on demand.

** Version Stamper (~scripts/update_version_build_numbers.sh~)
Xcode build phase script. Reads version from git tags, stamps
~CFBundleVersion~ and ~CFBundleShortVersionString~ into the built plist.

* Build System

Build tasks are defined in the ~justfile~ at the project root:

| Recipe        | Description                              |
|---------------+------------------------------------------|
| ~just build~  | Build Hammerspoon.app (Debug by default) |
| ~just clean~  | Wipe build dir + xcodebuild clean        |
| ~just test~   | Run tests (requires build first)         |
| ~just docs~   | Build all documentation formats          |
| ~just docs-lint~ | Lint docs without building            |
| ~just rebuild~ | Clean + build                           |

Dependencies are managed via mise (~mise.toml~). Only ~just~ itself remains
as a managed tool. SPM packages are resolved by Xcode automatically.
